# 小手机自定义 APP 制作说明（第 6-8 节）

## 6. 权限清单

`permissions` 只声明实际会用到的能力。

### 6.1 常用

* `app.data.read` / `app.data.write`：读写本 APP 私有数据。
* `app.assets.read`：读取本 APP 随包资源。
* `app.manifest.read`：读取 manifest 和 SDK 能力摘要。
* `characters.read`：读取角色基础信息。
* `ai.generate`：让指定角色基于 APP 任务生成内容，但不自动发送到聊天室。
* `chat.read`：读取授权范围内的聊天会话和历史。
* `chat.read.background`：APP 未打开时后台监听聊天消息。
* `chat.write` / `chat.sendMessage`：发送普通聊天消息，或写入 APP 事件历史。
* `chat.sendCard`：向角色聊天室发送 APP 卡片。
* `chat.requestReply`：请求角色根据已写入的历史或卡片回复。
* `ui.toast`：显示短提示。
* `ui.notification`：显示通知。

### 6.2 角色 / 用户 / 记忆

* `characters.state.read` / `characters.state.write`：读写角色状态。
* `characters.relations.read`：读取角色关系。
* `user.profile.read` / `user.persona.read` / `user.preferences.read`：读取用户资料、人设、偏好。
* `memory.readCore` / `memory.readLongTerm` / `memory.readShortTerm` / `memory.search`：读取或搜索记忆。
* `memory.write`：写入角色记忆。
* `memory.suggest`：提交记忆写入建议。

### 6.3 进阶能力

* `ai.chat` / `ai.embed` / `ai.classify`：高级 AI 会话、向量、分类。
* `ai.generateImage`：调用宿主已配置的生图 API。
* `network.fetch`：访问 manifest `network.allowedDomains` 里声明的域名。
* `voice.tts` / `voice.stt` / `voice.clone` / `voice.readProfiles`：语音生成、识别、克隆、读取声音配置。
* `chat.contacts.write`：修改联系人状态（拉黑、解除拉黑、免打扰）。
* `chat.tools`：注册 AI 可调用工具。
* `world.read`：读取世界书。
* `calendar.read` / `calendar.write`：读写日程。
* `media.pick` / `media.save`：选择或保存媒体。
* `media.put` / `media.get` / `media.delete`：媒体库，db 里只存引用。
* `voice.play` / `voice.stopPlayback` / `voice.pausePlayback` / `voice.resumePlayback`：音频交给宿主播放（iOS 上必用）。
* `notifications.read` / `notifications.write`：通知和桌面红点。
* `tasks.schedule`：后台定时任务（浏览器关闭时不运行，重开补跑）。
* `wallet.read` / `wallet.pay`：读取钱包 / 从钱包扣款。

## 7. 前端要求

1. 输出**可直接运行**的 HTML/CSS/JS，不要求用户安装 npm 或构建工具。
2. 页面跑在手机尺寸 iframe 中，必须适配**竖屏和触摸**操作。
3. 宿主会在**右上角**悬浮一个半透明的系统返回胶囊。**不要把关键按钮放右上角**；左上角可正常放标题或返回。
4. 内容很多时，在 APP 内部做滚动区域，避免横向滚动。
5. 不要使用会要求跨域权限的远程脚本；图片、字体、CSS 建议放进 `assets/`。

建议使用安全区变量：

```css
html, body { width: 100%; min-height: 100%; margin: 0; }
* { box-sizing: border-box; }
.app {
  min-height: 100dvh;
  padding: var(--ai-phone-app-safe-top, 88px) 16px var(--ai-phone-app-safe-bottom, 24px);
}
button, input, textarea { font: inherit; }
button { min-height: 44px; }
```

## 8. 实现流程

1. 先做单 HTML 原型，跑通 UI 和交互。
2. 再补 `manifest.json` 和 `icon.png`。
3. 只声明真实用到的权限。
4. 需要和聊天深度联动时，再补 `presets.json`。
5. 先本机测试，确认卡片、聊天感知、记忆写入都符合预期，再发布市场。
